# 우리만의 여행 가이드북 — 최종 제품 설계

> 확정일: 2026-07-29
>
> 상태: 사용자 승인 완료
>
> 구현 기준: 이 문서가 기존 Phase 1·Trip Control 문서와 충돌하면 이 문서를 우선한다.

## 1. 제품 정의

- 제품명: **우리만의 여행 가이드북**
- 형태: 두 사람이 여행 전·중·후를 함께 관리하는 설치형 PWA
- 디자인 방향명: `Trip Control`
- 핵심 가치: 감성 기록보다 여행 현장에서 필요한 정보와 다음 행동을 빠르게 보여준다.
- 시드니 전용이 아니라 여러 여행을 저장하는 여행 서재 구조를 유지한다.
- 회원가입을 추가하지 않고 현재 owner(소유자)·partner(파트너) 기기 연결 구조를 유지한다.

## 2. 전역 구조

### 여행 서재

- 예정·여행 중·완료 여행을 한곳에서 관리한다.
- 여행 카드를 누르면 해당 여행의 Trip Control로 들어간다.
- 삭제 여행은 현재의 30일 휴지통·복구 규칙을 유지한다.

### 여행 내부 하단 메뉴

| 메뉴 | 책임 |
|---|---|
| 오늘 | 여행 단계에 맞는 최우선 정보와 다음 행동 |
| 일정 | 날짜별 일정 확인·추가·수정·삭제 |
| 지도 | 저장 장소, 투표, 위치 확인, Google Maps 연결 |
| 도구 | 예약, 준비물, 메모, 검색, 활동, 환율, 설정 |

## 3. 여행 단계 전환

여행 상태는 수동 상태값보다 확정된 여정 경계시각을 우선해 계산한다.

| 단계 | 기준 |
|---|---|
| 여행 전 | 출국편 출발 예정시각 이전 |
| 여행 중 | 출국편 출발 예정시각 이상이며 귀국편 한국 도착 예정시각 이전 |
| 귀국 후 | 귀국편 한국 도착 예정시각 이상 |

- 두 시각은 timezone offset이 포함된 ISO datetime으로 저장한다.
- 경계시각이 없거나 잘못되면 기존 `trip.status`를 fallback으로 사용하고 설정 보완을 안내한다.
- 여행 중 날짜·일정 계산은 여행지 IANA timezone을 사용한다.
- 상태 전환은 앱 재진입, foreground 복귀, 자정 변경, snapshot 동기화 때 재평가한다.
- 서버 저장값을 매분 자동 mutation하지 않는다. UI의 파생 상태로 계산해 오프라인에서도 동일하게 동작시킨다.

## 4. 여행 전 홈

- 감성 커버 이미지를 가장 크게 보여준다.
- 출발일까지 남은 날짜와 목적지·여행기간을 간결하게 표시한다.
- 본문 최상단에는 **긴급 누락 정보**만 우선 표시한다.
- 누락 우선순위는 항공편·숙소·필수 예약·여권/필수 준비물 순이다.
- 전체 체크리스트와 준비 진행률은 별도 버튼으로 열고 홈을 체크리스트로 채우지 않는다.
- 확정 예약, 임박한 결제, 파트너 미연결처럼 즉시 해결해야 할 항목만 행동 버튼을 제공한다.

## 5. 여행 중 홈

- 여행지 현지시간을 기준으로 현재 날짜를 결정한다.
- 첫 카드에 `다음 일정 + 이후 일정 2개`를 시간순으로 표시한다.
- 카드 배치 우선순위는 다음과 같다.

1. 다음 일정과 이후 2개
2. 날씨 상세
3. 지도 진입
4. 현재 위치 주변 저장 장소

- 일정 카드에는 시작시각, 장소, 이동수단, 예약 연결 상태를 표시한다.
- 완료된 일정은 다음 일정 탐색에서 제외한다.
- 날씨가 최신값이 아니면 마지막 갱신시각과 오프라인/샘플 상태를 명시한다.
- 위치 권한이 없거나 오프라인이면 주변 장소 대신 저장 장소 바로가기를 표시한다.

## 6. 장소와 지도

- 장소를 누르면 먼저 앱 내부 상세카드를 연다.
- 내부 상세에는 이름, 분류, 주소, 설명, 저장자, 두 사람의 투표, 연결 일정을 표시한다.
- 앱에 저장된 영업시간은 실시간 확정값처럼 표시하지 않는다.
- 최신 영업정보·최신 리뷰·실제 길찾기는 Google Maps 외부 연결로 제공한다.
- 외부 링크는 검증된 HTTPS만 새 창으로 열고 `noopener noreferrer`를 적용한다.
- 온라인이고 좌표가 있을 때 MapLibre 지도를 사용한다.
- 오프라인·지도 로드 실패·좌표 없음에서는 저장 장소 목록이 완전한 fallback이 된다.

## 7. 오프라인과 데이터

오프라인에서도 다음을 확인할 수 있어야 한다.

- 일정
- 저장 장소
- 준비물
- 메모
- 예약정보
- 마지막으로 저장한 환율
- 지도 저장상태

현재의 IndexedDB snapshot cache·outbox·version conflict 구조를 유지한다.

- 오프라인 변경은 같은 idempotency key로 재전송한다.
- 충돌은 자동 덮어쓰지 않고 `내 수정 유지 / 최신 내용 사용`을 사용자가 선택한다.
- 개인 준비물과 개인 메모는 상대 snapshot·검색·활동에 노출하지 않는다.
- 예약번호는 기본 마스킹하고 사용자가 누르는 동안만 표시한다.
- 내보내기·가져오기는 개인정보와 세션 토큰을 제외한 버전 명시 데이터만 사용한다.
- 원본 데이터 삭제·덮어쓰기는 반드시 확인 단계를 거친다.

## 8. 테마·모션·접근성

- 라이트·다크·시스템 테마를 지원한다.
- 화면 전환, bottom sheet, dialog는 부드럽게 이동한다.
- 탭, 버튼, 필터는 즉시 반응하는 짧은 피드백을 사용한다.
- 애니메이션은 transform·opacity 중심으로 구현한다.
- `prefers-reduced-motion`에서는 짧은 fade만 남긴다.
- 터치 대상은 최소 44×44 CSS px을 유지한다.
- 모든 핵심 기능은 키보드와 스크린리더로 사용할 수 있어야 한다.

## 9. 귀국 후 홈

- 사용자가 고른 대표 사진 1장을 크게 표시한다.
- 대표 사진은 앱이 자동 추천하고 사용자가 언제든 변경할 수 있다.
- 핵심 행동은 `여행 기록 보기`와 `다시 여행 보기` 두 개다.
- 정산이 남아 있을 때만 정산 카드를 표시한다.
- 정산 완료 뒤에는 정산 카드를 홈에서 숨긴다.

## 10. 추억 쇼츠

### 범위

- 앱 내부에서만 다시 본다.
- 초기 버전에서는 MP4 저장·외부 공유를 제공하지 않는다.
- 세로 화면으로 고정한다.
- 사진·영상만 노출하고 시간·장소·메모는 표시하지 않는다.

### 자동 구성

- 앱이 대표 장면을 자동 선별하고 시간순으로 배치한다.
- 기본 자동 구성은 2분 이내다.
- 사용자 편집 결과의 절대 상한은 3분이다.
- 3분 초과 시 유사·연속 장면, 화질이 낮은 장면, 정보가 적은 장면 순으로 제외한다.
- 제외된 원본은 삭제하지 않고 제외 목록에서 확인한다.
- 사용자는 장면 추가·제외·순서 변경·교체가 가능하다.
- 제외 장면을 복원할 때는 포함 장면을 직접 골라 나란히 비교한 뒤 교체한다.
- 새 장면은 교체한 장면의 타임라인 위치를 그대로 사용한다.
- `자동 구성으로 되돌리기`와 직후 `실행 취소`를 제공한다.

### 재생

- 가로 미디어는 원본 전체를 표시하고 남는 영역은 같은 미디어의 흐린 배경으로 채운다.
- 진행 바와 조작 버튼은 기본적으로 숨기고 화면 탭 시 표시한다.
- 화면 탭은 재생을 멈추지 않는다.
- 일시정지는 조작 UI 버튼으로 하며 다시 재생하면 정확한 시점부터 이어간다.
- 재진입 시 시청 기록이 있으면 `이어보기 / 처음부터`를 선택한다.
- 이어보기는 마지막으로 보던 장면의 처음부터 시작한다.
- 백그라운드·화면 꺼짐에서는 자동 일시정지하고 복귀 후 같은 장면 첫 화면에서 사용자의 재생 입력을 기다린다.
- 휴대폰의 화면 자동 꺼짐 설정을 그대로 따른다.
- 좌우 화면 영역 탭으로 이전·다음 장면으로 이동한다.

### 음악

- 저작권·재배포가 허용된 기본 음악 5~8곡을 앱에 포함한다.
- 감성·활기·여유·야경·바다·도시 분위기를 포함한다.
- 음악 변경 시 장면은 유지하고 crossfade(교차 전환)한다.
- 선택 음악은 해당 여행 다시 보기에 저장한다.
- 영상 장면에서는 배경음악을 자동 감쇠하고 영상 원음을 재생한다.
- 곡별 원문 라이선스와 출처를 저장소에 기록한다.

### 미디어 저장 원칙

- 웹 PWA는 휴대폰 갤러리의 원본 파일 경로를 영구 참조할 수 없으므로 선택한 미디어를 앱의 비공개 저장소로 복사한다.
- 서버 사용 시 private R2 object와 권한 확인 API를 사용하고, 오프라인 재생용 축소본을 IndexedDB에 캐시한다.
- 원본 휴대폰 파일을 삭제해도 이미 가져온 앱 사본은 유지된다.
- 앱에서 장면을 삭제할 때만 실제 저장 사본 삭제 여부를 별도로 확인한다.
- 미디어는 여행 member만 접근할 수 있고 공개 URL을 만들지 않는다.

## 11. 범위 제외

- Spotify·YouTube Music 등 외부 음악 서비스 연동
- 사용자 기기의 음악 파일 사용
- MP4 생성·다운로드·SNS 공유
- 자동 AI 영상 생성
- 공개 여행 페이지
- 실시간 영업시간을 앱 자체 데이터처럼 보장하는 기능

## 12. 수용 기준

- 제품명이 UI, PWA manifest, 테스트, 문서에서 `우리만의 여행 가이드북`으로 일치한다.
- 같은 여행이 경계시각에 따라 여행 전·중·후 홈으로 정확히 전환된다.
- 여행 중 홈은 현지시간 기준 다음 3개 일정을 우선 노출한다.
- 온라인 API가 실패해도 승인된 오프라인 핵심 데이터가 열린다.
- 귀국 후 대표 사진과 다시 보기 진입이 동작한다.
- 추억 쇼츠가 기본 2분·최대 3분 제한과 미디어·음악 규칙을 지킨다.
- 라이트·다크·reduced motion·모바일 세로 화면·키보드 조작 검증을 통과한다.
- 기존 일정·장소·예약·준비물·메모·검색·동기화 기능에 회귀가 없다.
